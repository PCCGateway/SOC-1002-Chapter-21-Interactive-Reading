CHAPTER 21 INTERACTIVE READING WORKSHOP

Upload index.html to a GitHub repository, then enable GitHub Pages in Settings > Pages > Deploy from a branch > main / root.

Students can use the published URL on any device. Responses auto-save in the current browser. On shared computers, students should download their JSON progress and upload it next time. They can print/save a PDF for submission.

No server, accounts, tracking, or external libraries are required. The reading links open OpenStax in another tab.
